# Render a talking-head Video with the tested settings, and measure any length not yet tested

A Video is one continuous lip-synced talking head made from the Voiceover. The longest continuous head rendered and approved so far is 21-27 s, but a Video runs the whole Script (about 1.5-2 minutes for `script-01`), so longer renders are expected. Do not claim a long render is good until the Operator has watched all of it. The first full `script-01` render, with the settings in `config/infinitetalk-graph.json` as of October 2026, had lurching head motion, exaggerated "oo" mouth shapes and appearance drift after about 50 s; test setting changes on a 10 s slice first. Report the render time and any drift or colour shift you see. The full-length `script-01` render is still open.

- The raw output is 480×832 at 25 fps for 9:16, and 832×480 for 16:9. Upscale the finished Video to the Channel's Format (9:16 at 1080×1920, 30 fps; 16:9 at 1920×1080, 30 fps). The finished file is named `videos/<script>.<width>x<height>.mp4`, for example `videos/script-01.1080x1920.mp4`, not `<script>.mp4`. An older note may give the bare name, so look for the sized name before reporting a missing Video.
- 16:9 is on (`SIXTEEN_BY_NINE_VERIFIED = True` in `cli.py`) since the Operator approved the 8.0 s 832×480 test render. That render, on the old Q8 settings, took 560 s in the face engine and peaked at 11,426 of 12,227 MiB VRAM; the tuned graph took 431.6 s at 10,735 MiB (see the timing notes). Check free VRAM first. Full-length 16:9 Videos are still unmeasured.
- Never edit the Likeness. Crop a copy to the Channel's Format for each Video.
- The render needs about 10 GB of free VRAM. Check it first, as described in `media-render-verification`.
- A probe that calls `make_video` directly skips `cleared_gpu`, and with it the free-VRAM check. If free VRAM is below about 10 GB, stop and ask the Operator; do not start the probe anyway.
- A short-test driver that calls the face engine directly (`InfiniteTalkEngine.installed_in(root)`) skips `cleared_gpu` too. Check free VRAM yourself first, and log it.
- A driver that builds `InfiniteTalkEngine` by hand must use the paths in `src/clonecraft/infinitetalk.py`: `vendor/face-env/bin/python`, `vendor/ComfyUI/main.py` (the entry file, not the folder; the folder fails with `can't find '__main__' module`), `models/comfy`, and `config/infinitetalk-graph.json`. Pass absolute paths to the graph, since a relative path breaks when the driver runs from a scratch folder.
- Scratch drivers run in the main environment, which has no PIL. Resize the portrait with ffmpeg (`-vf scale=480:832`) rather than adding a project dependency for a probe.
- Attention-kernel probe on random 1x12x1024x128 bf16 inputs against SDPA: SageAttention 3 (FP4) gave mean abs error 0.0077 and cosine 0.98162; SageAttention 2.2.0 gave mean abs error 0.0015 and cosine 0.99928. Treat SA3 output as lossier, and let the Operator judge a real render by eye before switching.
- Before writing a short-test driver, read `_video` in `src/clonecraft/video.py` and copy its current order (`faces_for`, `render_faces`, `assemble`). A driver copied from an older probe goes stale when the face-only path changes; a 5 s driver was stale in this Channel, so the 15 s test was rewritten against `_video`.
- Write test renders to the session scratch folder, never to `videos/`, so the Channel's Video and its sized name stay untouched. Report the scratch path and its log.
- Tuned settings (`config/infinitetalk-graph.json`): fp8 weights, the `multitalk` scheduler, merged LoRA, 6 steps, 34 blocks swapped. On the same 5 s 9:16 test the face engine fell from 370.0 s to 301.9 s; on the 8 s 16:9 check it fell from 560.4 s to 431.6 s. A full-length `script-01` on these settings is unmeasured; the tuning doc's scaled estimate is about 3,100 s of face engine.
- Keep the tuning's limits: `blocks_to_swap` stays at 34 or above (28 and below ran out of memory in the sampler); `fp8_e4m3fn_scaled_fast` needs `merge_loras: true` on the LoRA node, or the loader raises `NotImplementedError`; prefetch above 1 is slower and ran out of memory at 4.
- The code overrides only the image, the audio, the frame count and the frame size (`src/clonecraft/infinitetalk.py`). The sampler, scheduler, block swap and LoRA come from the graph file, so a settings change is a graph edit followed by a short test.
- The per-job watchdog is `JOB_TIMEOUT_S`, 3,600 s, and its comment describes one Face section. The recorded full-length face time of 4,058 s is above that, so confirm how a long Face section is split into jobs before trusting a full-length run.
- The 77.5 s `script-01` Voiceover took about six minutes on this card, finishing at 08:43 CDT on 2026-10-26; the Video is the long step.
- Timing on the old Q8 settings, measured on the 12 GB card: a 5.0 s 9:16 Video took 451 s in total (face engine 437.7 s, about 90 s of wall time per second of Video). Peak was 4.9 GB allocated and 8.8 GB reserved, and the frame window sets that peak, not the clip length. Measured full length: the 77.6 s `script-01` Video took 4,058 s in the face engine and 4,254 s in total (about 55 s of wall time per second of Video), peaking at 9.09 GB reserved. Observed on `script-01`: a run launched at 17:20 CDT reached its last face window (1872-1953) about 1 h 19 min later, then the process was gone with no EXIT line and no Video. Launch the full render detached, as in `media-render-verification`, and log `EXIT=` so a lost run is visible.
- Under transformers 5.x, ComfyUI-WanVideoWrapper's `multitalk/wav2vec2.py` must be patched before InfiniteTalk runs, because the encoder no longer returns per-layer hidden states. Restart ComfyUI after patching.
- Before queuing a batch of probes, check that every custom node and Python package the graph's settings need is importable in the face engine's environment. A colour-matching probe failed in the sampler with `ModuleNotFoundError: No module named 'color_matcher'` after the earlier probes had passed, so the package has to be installed before the batch starts.
- Budget probe batches by their real cost: 10 s 9:16 probes took 689–747 s each in the face engine (about 12 min), so a six-probe batch takes about 75 min. Do not extrapolate their wall time as if it were linear with length.
- Pinned versions: `config/face-requirements.txt`. Graph and settings: `config/infinitetalk-graph.json`.
